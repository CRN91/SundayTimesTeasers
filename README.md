> Development has ended

The continuous assessment of the second year module Computer Languages and Representations taught by Prof. David Wakeling.

Each week *The Sunday Times* newspaper publishes a [MindGames Teaser](https://www.thetimes.com/topic/teaser). This code solves a few of the exercises using Haskell.

## Usage

Each Teaser has a separate file, that can be run in Haskell to find the solution.
